# Before & after photos

Drop photos in this folder and they show up on
[floraskinwellness.com/results](https://www.floraskinwellness.com/results/)
a minute or two later. No code to edit.

## How to add a pair

1. On GitHub, open this folder (`results/photos`).
2. Click **Add file → Upload files**, drag in the two photos, then click **Commit changes**.

## Naming

Each pair is two files with the same name, ending in `-before` and `-after`:

```
2026-10-25-acne-before.jpg
2026-10-25-acne-after.jpg
```

- **Start with the date** (year-month-day). Newest pairs show first. The date is never shown on the site.
- **The words after the date become the caption.** `2026-10-25-acne-facial-3-months` shows as "Acne facial 3 months". Leave the words out (`2026-10-25-before.jpg`) for no caption.
- Use only letters, numbers and dashes. No spaces, and no client names.
- JPG, PNG or WEBP. If a photo comes off an iPhone as HEIC, export or share it as JPG first.
- A photo without its matching partner is ignored until the other one is added.

## Tips

- Crop both photos the same way, portrait (taller than wide). The site shows them at 4:5.
- Keep each file under about 1 MB so the page stays quick on phones. Most phones' "medium" or "large" export size is plenty.
- Only post photos the client has agreed to share, in writing.

## Removing a pair

Click a photo in this folder, then the trash icon (**Delete file**), and commit. Delete both halves.
